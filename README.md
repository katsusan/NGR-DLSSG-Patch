# NGR-DLSSG-Patch
patch for enabling DLSS Frame Generation in NGR

## How to install
1. Download patchdlssg.zip from release.
2. extract the two files in patchdlssg.zip to `KingLauncher\HOKWorld\WindowsNoEditor\NGR\Binaries\Win64`.
3. run install.bat to apply the patch.

## 如何安装
1. 下载release下的patchdlssg.zip压缩包
2. 把压缩包里的两个文件解压到王世界目录``KingLauncher\HOKWorld\WindowsNoEditor\NGR\Binaries\Win64`下.
3. 运行install.bat以安装。

## 注意事项/NOTE
由于本补丁需要注入，因此有一定的小黑屋风险，因此主攻PVP的用户请谨慎采用。   
Since this patch needs to be injected into the game, there would a risk for being bannned, please take extreme caution to adopt this patch,   
especially for PVP players.
