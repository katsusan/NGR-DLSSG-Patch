# NGR-DLSSG-Patch
patch for enabling DLSS Frame Generation in NGR

## How to install
1. Download patchdlssg.zip from release.
2. extract the two files in patchdlssg.zip to `KingLauncher\HOKWorld\WindowsNoEditor\NGR\Binaries\Win64`.
3. run install.bat to apply the patch.
4. Copy the content in `Config/Engine.ini` to `%LOCALAPPDATA%\NGR\Saved\Config\WindowsNoEditor\Engine.ini`.
5. It is 2x frame generation by default, go to NVIDIA APP for higher multiplier or dynamic frame generation.

## 如何安装
1. 下载release下的patchdlssg.zip压缩包
2. 把压缩包里的两个文件解压到王世界目录``KingLauncher\HOKWorld\WindowsNoEditor\NGR\Binaries\Win64`下.
3. 运行install.bat以安装。
4. 把Config/Engine.ini里的内容复制粘贴到`%LOCALAPPDATA%\NGR\Saved\Config\WindowsNoEditor\Engine.ini`里然后保存并关闭。
5. 默认是2倍帧生成，想要多倍或者动态多帧生成去Nvidia APP里调节。
